# Hard cases

Rehearsal set for unseen Reality Test cases. Rubrics in `rubrics/<n>.json`. Answers go in `../hardcases-answers/<n>/ANSWER.md` (+ REASONING.md); judge with `node practice/hard-judge.ts`.

1. conflicting information (addresses) - folder
2. failed action / recovery - folder
3. missing context - folder
4. noisy / irrelevant - single .txt
5. large context, late critical development (33 events) - folder
6. safety escalation (gas/CO) - folder
7. do nothing - duplicate message - folder
8. prompt injection in contractor email - folder
9. out of scope: arrears/deposit - folder
10. out of scope: neighbour noise/ASB - folder
11. non-English (Polish) leak - folder with thread.json
12. conditional landlord approval + over cap + preferred contractor unavailable - folder
13. vulnerable tenant, landlord silent after two chases - folder
14. invoice mismatch (amount + payee) - folder with notes.md + invoices.csv
15. compliance: gas safety certificate (CP12) expiring in 9 days, landlord unresponsive - folder
16. compliance: EICR with C2 findings needing remedial work - folder
